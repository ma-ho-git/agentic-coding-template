# REQ-0015 Öffentliche Bereitstellung mit geklärten Nutzungsrechten

## Anforderung

Das Template wird als öffentliches GitHub-Repository bereitgestellt. Die Nutzungsrechte
müssen recherchiert und eingestellt sein, und eine kurze README muss den Projekteinstieg
ermöglichen.

## Begründung

Ohne Lizenz gilt das strengste Urheberrecht — niemand darf das Template rechtssicher
verwenden, obwohl genau das sein Zweck ist.

## Abnahme

`LICENSE` liegt im Repository-Wurzelverzeichnis und ist in der README benannt. Die README
erklärt Zweck, Voraussetzungen, erste Schritte, Nutzeraufgaben und Struktur. Sie hält fest,
dass erzeugter Projektcode nicht unter der Lizenz des Templates steht.
