# Glossar

## Kurz

Das verbindliche Vokabular der Fachdomäne. Kein Beiwerk: die Coderegel „Namen aus maximal
drei Wörtern, für Menschen aussagekräftig" (`.claude/rules/code-quality.md`) ist nur
einlösbar, wenn feststeht, wie die Dinge heißen.

**Regel:** Ein Begriff, eine Schreibweise, im Gespräch wie im Code. Wer im Glossar steht,
heißt im Code genauso — keine Synonyme, keine Abkürzungen daneben.

*Beim Projektstart mit den Begriffen aus der Anforderungserhebung füllen und danach pflegen.*
